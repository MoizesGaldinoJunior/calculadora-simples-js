CALCULADORA SIMPLES EM JAVASCRIPT

Uma calculadora simples feita com HTML, CSS e JavaScript. Esta calculadora permite operações matemáticas básicas e possui suporte a entrada via teclado.

📌FUNCIONALIDADE

-   Adição, subtração, multiplicação e divisão
-   Interface intuitiva e responsiva
-   Suporte a entrada via teclado
-   Substituição segura do eval() para cálculos
-   Display que reseta ao digitar um novo número após um cálculo

🚀COMO USAR
1️⃣Clonar o repositório
git clone https://github.com/MoizesGaldinoJunior.calculator-js.git
cd calculadora-js
2️⃣ Abrir o arquivo
Basta abrir o arquivo index.html no navegador

🛠️ESTRUTURA DO PROJETO
calculadora-js/
│-- index.html # Estrutura da calculadora
│-- style.css # Estilos visuais
│-- script.js # Lógica e interatividade
│-- README.md # Documentação

ATALHOS DO TECLADO
Números e operadores (0-9, +, -, \*, /) => Inserem valores
Enter (Enter) => Calcula o valor digitado
Backspace => Apaga o último número digitado
Esc => Apaga o display
